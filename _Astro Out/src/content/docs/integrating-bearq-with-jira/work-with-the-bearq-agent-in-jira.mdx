After setup, you collaborate with the BearQ agent on individual work items.

## Assigning or Triggering the Agent

- **Assign the agent:** Open the work item, and in the Assignee field, search for and select the BearQ agent.
- **Trigger the agent automatically:** Set up a rule in your Jira workflow to assign the BearQ agent when a work item reaches a specific status, such as when it moves to the testing stage.
- **Chat with the agent in Rovo**: Open Rovo, select the BearQ QA Lead agent, and chat with it about your QA activities.

When the agent receives the work item, BearQ's QA Lead authors test cases from the work item's context and runs them against your application.

## Reviewing and Approving the Results

BearQ reports its response on the work item in the Agents panel. Review the response there and approve it to accept the work. Only the person who assigns the agent, or who triggers it through a workflow transition, can interact with it directly. Anyone with access to the work item can see that the agent was triggered, and you can share its output with your team.

## Asking Questions to the Agent

Mention the BearQ agent in a comment on the work item to ask about its status, for example, when it last ran a test. The agent responds in the comment thread. To see more details, open BearQ to view the work queue and the task or test details.
