## Improvements

## Reliable test execution and enhanced verification

Steps now run more reliably, with automatic validation that confirms each step executes as expected. Authored tests include enhanced verification steps that actively confirm the page state and are backed by a script, giving you greater confidence in your test results

## Unified Tests View

The redesigned tests view lets you search across all test types from a single place, including archived, draft, and regression tests. To learn more, see [Tests](/tests/).

## Improved test editing

Ask the QA Lead to make the required updates and keep the test steps intact. Alternatively, use the editing options to allow  to overwrite the existing steps.
