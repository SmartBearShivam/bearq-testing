## What's New

- **Multiple environments and credentials**

  Store several environment configurations in a single workspace, set one as the default, and switch between them at any time. Override the environment for an individual run and pass an optional environment parameter through the public API. Credentials are stored encrypted for each organization, and admins can clone an existing workspace in one step.
- **BearQ Agent on the Atlassian Marketplace**

  Add BearQ directly from the Atlassian Jira Agent Marketplace. When you come from Jira, you’ll see a tailored sign-in and trial setup, and a new post-onboarding screen explains how to configure the integration and keep working in Jira.
- **Manual step editing with metadata**

  View a step's configuration metadata in plain text and edit it directly, going beyond editing only the step description.
- **Streaming subtask results**

  Watch subtask status and results stream into the activity log in real time, matching the subtask's own detail page.
- **Smarter page matching**

  BearQ now recognizes pages that are effectively the same even when their URLs differ and use no parameters, reducing duplicate entries in the application model.

## Bug Fixes

- Fixed issue where View Failed Tests, opened from the Regression Test Trend block, displayed inconsistent timeframe and date information.
- Resolved an issue where the Review and Fix Tests page listed every test under Failing instead of only the failing tests.
